# 用途页签、分段编辑与音视频边界

状态：2026-11-08，本轮功能、两套环境回归、真实画布往返验证与安装同步完成。沿用既有节点与连线；不纳入跨重启存档、版本状态面板和画质防漂移。验收与部署记录见 [VALIDATION.md](../docs/VALIDATION.md)。

## 本轮范围

- 提示词窗口在完整 JSON 与逐段编辑之间双向切换，共用原 segment_prompts 值；保留旧字符串条目，错误原文不丢失。后续结构化条目承载本段提示、对白和边界设置。
- 一采先选整段生成、长视频接力、分段编辑、局部重绘、载入或复用；二采先选常规、局部、更新一采或复用。原生参数与执行语义继续作为唯一后端来源，Tabs 不增加重复采样模式。
- 规划器按切分规则使用 Tabs；上下文按参考用途与音频用途分组，保留输入接口和隐藏值。
- 音频明确生成、参考生成和指定音轨锁定。旧工作流默认保持参考参与行为；指定音轨经目标 AV 原生遮罩约束，原始波形继续通过已有音频分支输出。
- 连续接力与明确切镜分别规划。连续边界默认 22 帧；切镜不继承旧画面，H3 合法窗口所需填充单独裁除。输出镜头边界供二采重分段使用，禁止跨镜头继承视频边界。
- 对白仅进入当前段条件，时间从交付窗口换算到采样窗口；提示词时间约束不承诺模型逐字遵守。保持集中条件编码，不恢复逐段切换 CLIP。

## 验证边界

检查旧工作流字段顺序与接线、JSON 往返及异常保留、各 Tabs 参数显隐与保存、外部文本输入、混合镜头的 H3 相位/音视频长度/去重、指定音轨遮罩与原输入不变、二采镜头隔离、缓存失效及局部回修。复用现有 CPU、前端和原生执行测试；真实模型对照与界面验收单独记录。工程检查不等于无多余对白或视觉无缝。
