专门为 **MiniMax H3**、**LTXV** 及通用长视频设计的**工业级潜空间分段采样与时序总控套件**：
* 🟣 **规划总控**：`PJ分段规划器 (时序总控/可视播放器)`（输入视频/音频实时渲染内置试听播放器，点击分段精准播放，一处规划全局绝对同步）
* 🟢 **一采节点**：`PJ一采分段重抽采样器`（支持参考视频时钟同步、分段独立 Seed、缓存一键锁定与单段极速重抽，支持最高20段自适应）
* 🔵 **二采节点**：`PJ二采分段精修采样器`（2.0MP 高清无损分段精修、防爆显存、自动卸载 20GB DiT 大模型）

---

## 📖 解决的工业化核心痛点 (Why This Toolkit?)

在长视频（10秒 ~ 30秒+）与局部换鞋/换人工作流中，创作者面临数个致命瓶颈：

1. **时钟不统一导致的接缝与音画割裂**：
   一采和二采如果各自分段，稍微差 0.5 秒就会导致二采接缝错位、音视频对齐丢失。
   👉 **本套件方案**：引入 **`PJ分段规划器` (时序总控)**，输出统一的 `PJ_SEGMENT_PLAN` 时钟总线，一采和二采直接连接该总线，全局切分点、重叠区完全原子级对齐！
2. **长视频审片无法快速定位瑕疵段落**：
   看到视频第 7.5 秒脚部变形，传统方式要在各个节点里手动算第几段。
   👉 **本套件方案**：
   - 规划器内置 **可视分段播放器**：接入 `IMAGE` 与 `AUDIO`，画布上直接看到每段起止秒数与帧数，点击 `[▶ 播放本段]` 即可单独无限循环试听该段！
   - 采样器支持 **按缺陷秒数重抽 / 精修**：直接输入 `7.5` 秒，节点自动识别并精准锁定重跑对应分段！
3. **分段数固化与界面冗余**：
   传统节点只能固定 4 段或 8 段，做 5 段空 3 段，做 15 段又不够用。
   👉 **本套件方案**：**全动态前端伸缩**！输入 5 即显示 5 段，输入 15 即显示 15 段，点击 `🔄 刷新分段适配` 节点尺寸自动收缩贴合，清爽无杂乱！
4. **二采画质崩溃的根源在“一采”**：
   二采效果不好，90% 是一采对应那几秒的 Latent 骨架就抽歪了。一采从源头按二采时间线精准切分，**哪段没抽好，直接单独重抽该段一采（仅需 20 秒）**，好的段落 0 秒读取缓存！
5. **二采 40GB+ 显存爆炸与尾部 VAE 崩溃**：
   2.0MP 高清潜空间直接二采会突破 40GB 显存，且 DiT 滞留 GPU 会导致随后的 VAE 解码 OOM。
   👉 **本套件方案**：二采串行无损采样 + **二采完成后自动卸载 20GB DiT 主模型**，显存峰值直接暴降至 8.6GB，彻底杜绝爆显存。

## ⚡ 三大节点功能详解

### 1. 🟣 `PJ_SegmentPlanner` (PJ分段规划器 / 时序总控与可视播放器)
* **前置时钟总控**：支持通过视频总时长（秒）、总帧数或直接传入 `images` 自动推算总时间。
* **内置试听播放器 (带音频)**：接入上游 `images` 与 `audio`，节点自动合成轻量预览视频并渲染播放器，每段提供 `[▶ 播放本段]` 按钮，点击即跳转对应时段并单段循环播放，音画同频！
* **一键时钟总线 (PJ_SEGMENT_PLAN)**：输出统一的总线接口，一采和二采直接连线即可继承全部切片规划。

### 2. 🟢 `PJ_FirstPass_SegmentSampler` (PJ一采分段重抽采样器)
* **参考视频时钟同步**：自动将参考视频潜空间精准切片，每段各自看到对应时间段的原视频姿态；
* **分段独立种子 (Seed Offset)**：支持最高 20 段各自独立的随机种子微调；
* **智能缓存锁定 (Lock Cache)**：好段一键打勾锁定，下次运行 **0 秒直接提取**，不耗费 1 秒 GPU 算力；
* **灵活重抽控制**：支持下拉单选 `仅重抽第X段`、`按缺陷秒数重抽` 或 `自定义指定分段 (如 2, 5)`。

### 3. 🔵 `PJ_SegmentSampler` (PJ二采分段精修采样器)
* **纯潜空间时空切片**：直接在 Latent 时间轴切片，0 编解码画质损耗；
* **51 帧 RoPE 相位整数吸附**：锁定 H3 模型的 RoPE 周期步进，彻底消除嘴型漂移与双唇鬼影；
* **全局噪声切片共享**：重叠区初始噪声完全一致，杜绝接缝闪烁；
* **100% 保留一采原音频**：直通一采高质量连续音频，杜绝声学相位抵消与爆音；
* **采样结束自动卸载模型**：将 20GB DiT 大模型移至 CPU，确保 VAE 解码拥有充足纯净显存。

  │   - 计算绝对切片点与重叠区                                  │
  └────────────────────────────┬────────────────────────────┘

             ┌─────────────────┴─────────────────┐
             │                                   │
             ▼                                   ▼
┌───────────────────────────┐       ┌───────────────────────────┐
│ 🟢 PJ一采分段重抽采样器   │       │ 🔵 PJ二采分段精修采样器   │
│ (单段重抽/缺陷秒数定位)   │       │ (2.0MP无损/自动卸载防爆显存│
