专门为 **MiniMax H3**、**LTXV** 及通用长视频设计的**全流程潜空间分段采样套件**：
* 🟢 **一采节点**：`PJ一采分段重抽采样器`（支持参考视频时钟同步、分段独立 Seed、缓存一键锁定与单段极速重抽）
* 🔵 **二采节点**：`PJ二采分段精修采样器`（2.0MP 高清无损分段精修、防爆显存、自动卸载 20GB DiT 大模型）

---

## 📖 解决的工业化核心痛点 (Why This Toolkit?)

在长视频（10秒 ~ 30秒+）与局部换鞋/换人工作流中，创作者面临两大致命瓶颈：

1. **二采画质崩溃的根源在“一采”**：
   二采效果不好，90% 是一采对应那几秒的 Latent 骨架就抽歪了。传统工作流中一采是不可分割的“黑盒子”，中间几秒不满意只能从头重跑整个 15 秒，费时 10 多分钟！
   👉 **本套件方案**：一采从源头按二采时间线精准切分，**哪段没抽好，直接单独重抽该段一采（仅需 20 秒）**，好的段落 0 秒读取缓存！
2. **长视频参考时钟漂移**：
   分段生成时，传统采样器不知道当前分段对应原参考视频的哪几秒。
   👉 **本套件方案**：内置 **参考视频时钟同步（Sync Ref Video）**，自动切出对应时间段的参考视频潜空间，动作与步态 100% 同频！
3. **二采 40GB+ 显存爆炸与尾部 VAE 崩溃**：
   2.0MP 高清潜空间直接二采会突破 40GB 显存，且 DiT 滞留 GPU 会导致随后的 VAE 解码 OOM。
   👉 **本套件方案**：二采串行无损采样 + **二采完成后自动卸载 20GB DiT 主模型**，显存峰值直接暴降至 8.6GB，彻底杜绝爆显存。

## ⚡ 双节点体系与功能详解

### 1. 🟢 `PJ_FirstPass_SegmentSampler` (PJ一采分段重抽采样器)

专门用于一采低清生成（0.4MP，Denoise = 1.0 全新生成骨架）：
* **参考视频时钟同步**：自动将参考视频潜空间精准切片，每段各自看到对应时间段的原视频姿态；
* **分段独立种子 (Seed Offset)**：第 1/2/3/4 段均拥有独立的随机种子控制；
* **智能缓存锁定 (Lock Cache)**：好段一键打勾锁定，下次运行 **0 秒直接提取**，不耗费 1 秒 GPU 算力；
* **单段重抽控制台**：下拉菜单一键切换 `仅重抽第2段`，GPU 集中算力 20 秒极速出新段，自动余弦平滑缝合成完整长潜空间！

### 2. 🔵 `PJ_SegmentSampler` (PJ二采分段精修采样器)

专门用于二采高清精修（2.0MP，超分降噪）：
* **纯潜空间时空切片**：直接在 Latent 时间轴切片，0 编解码画质损耗；
* **51 帧 RoPE 相位整数吸附**：锁定 H3 模型的 RoPE 周期步进，彻底消除嘴型漂移与双唇鬼影；
* **全局噪声切片共享**：重叠区初始噪声完全一致，杜绝接缝闪烁；
* **100% 保留一采原音频**：直通一采高质量连续音频，杜绝声学相位抵消与爆音；
* **采样结束自动卸载模型**：将 20GB DiT 大模型移至 CPU，确保 VAE 解码拥有充足纯净显存。

## 🎛️ 完整中文界面参数对照表

### 🟢 一采分段重抽采样器 (`PJ_FirstPass_SegmentSampler`)

| 参数名称 | 选项 / 类型 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- |
| `noise` | `NOISE` | - | 基础噪声源（可连接 RandomNoise 节点） |
| `guider` | `GUIDER` | - | 引导器（连接 BasicGuider，内含模型与提示词/参考条件） |
| `sampler` | `SAMPLER` | - | 采样算法（推荐 `er_sde` 或 `euler`） |
| `sigmas` | `SIGMAS` | - | 调度器步长（通常为一采全降噪，如 6 步） |
| `latent_image` | `LATENT` | - | 一采空潜空间（来自 `EmptyMiniMaxH3LatentAV`） |
| `分段模式` | `按秒自动切分 / 固定分段数 / 自定义切点` | 按秒自动切分 | 切分规划策略 |
| `单段时长` | 浮点数 (2.0 ~ 30.0s) | `6.0` | 自动模式下单段最大时长（建议 5.0 ~ 7.0 秒） |
| `重叠时长` | 浮点数 (0.0 ~ 10.0s) | `1.5` | 相邻分段重叠过渡时长（建议 1.0 ~ 2.0 秒） |
| `参考视频时钟同步`| `布尔值` | `True` | **【核心】自动按分段裁剪参考视频潜空间，动作精准对齐** |
| `重跑执行策略` | 下拉菜单 | 智能缓存 | `全部重新采样 / 智能缓存(仅重跑未锁定分段) / 仅重抽第1/2/3/4段` |
| `第1~4段锁定缓存`| `布尔值` | `False` | 打勾后跳过该段采样，0秒直接读缓存 |
| `第1~4段种子偏移`| 整数 (0 ~ 999999) | 0, 1, 2, 3 | 各分段独立种子微调控制 |
| `重叠区融合算法` | `余弦平滑(推荐) / 线性过渡 / 硬切` | 余弦平滑(推荐) | 接缝处交叉淡化平滑过渡算法 |
| `采样后卸载模型` | `布尔值` | `False` | 采样完成后是否卸载模型以给随后的 3D 超分腾空显存 |

### 🔵 二采分段精修采样器 (`PJ_SegmentSampler`)

| 参数名称 | 选项 / 类型 | 默认值 | 详细说明 |
| :--- | :--- | :--- | :--- |
| `noise` | `NOISE` | - | 随机噪声源（连接 RandomNoise） |
| `guider` | `GUIDER` | - | 引导器（连接 BasicGuider） |
| `sampler` | `SAMPLER` | - | 采样算法（推荐 `er_sde` 或 `euler`） |
| `sigmas` | `SIGMAS` | - | 调度器步长（二采高清精修，通常 2 步） |
| `latent_image` | `LATENT` | - | 输入待精修的高清潜空间（来自 3D 超分放大后的 AV Latent） |
| `分段模式` | `按秒自动切分 / 固定分段数 / 自定义切点` | 按秒自动切分 | 二采切分规划策略 |
| `单段时长` | 浮点数 (2.0 ~ 30.0s) | `8.0` | 自动模式下单段最大时长（建议 6.0 ~ 8.0 秒） |
| `重叠时长` | 浮点数 (0.0 ~ 10.0s) | `2.0` | 相邻分段重叠过渡时长（建议 1.5 ~ 2.5 秒） |
| `51帧整数吸附` | `布尔值` | `False` | 吸附到51帧/85音频步网格，确保绝对RoPE相位一致，杜绝嘴型漂移 |
| `重跑执行策略` | 下拉菜单 | 全部精修 | `全部精修 / 智能缓存 / 仅精修第1/2/3/4段` |
| `第1~4段二采锁定`| `布尔值` | `False` | 打勾锁定后跳过该段二采运算，0秒直接读取缓存 |
| `保留一采原音频` | `布尔值` | `True` | **100%保留一采原音频，杜绝声学相位抵消与爆音** |
| `二采后卸载模型` | `布尔值` | `True` | **二采后将 20GB DiT 移出显存，保卫后续 VAE 解码** |

## 🔌 工业化工作流连接拓扑

```
【输入条件】 Prompt + 目标鞋图 <Picture 1> + 参考动作视频 <Video 1>
                      │
                      ▼
【一采阶段 (0.4MP)】  [PJ一采分段重抽采样器] ◄─── (支持分段锁定，哪段不好单独重抽哪段！)
                      │ (输出完整平滑缝合的长视频低清 Latent)
                      ▼
【3D 超分放大】      [MinimaxH3LatentUpscaler3D] ──► 放大至 2.0MP 电影级高清
                      │
                      ▼
【二采阶段 (2.0MP)】  [PJ二采分段精修采样器] ◄─── (分段精修阻断显存爆炸，自动卸载模型)
                      │ (输出 2.0MP 高清精修 Latent)
                      ▼
【VAE 最终解码】     [VAEDecode] (8~9GB 极低显存下解码出超清长视频！)
```
