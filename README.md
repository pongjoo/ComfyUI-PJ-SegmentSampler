# ComfyUI-PJ-SegmentSampler

MiniMax H3 的分段规划、一采重抽与二采精修节点。保留现有节点标识、端口类型和旧工作流参数迁移。

## 节点与连接

`PJ_SegmentPlanner → 一采 / 二采`，一采输出可经已有潜空间放大节点送入二采。

- **PJ_SegmentPlanner**：统一分段规则；接入潜空间时读取真实音视频长度，未接入时按约15秒预览。执行后仪表盘自动展开全部分段。图像和音频可用于预览播放器。
- **PJ_FirstPass_SegmentSampler**：整段或分段一采、分段种子偏移及锁定重用。第二输出实际是首段潜空间，现已据实命名，不是列表。
- **PJ_SegmentSampler**：分段二采，输出完整采样结果和完整去噪结果，可保留输入音频潜空间。

## H3 时间规则

- 模型时钟固定24fps；完整视频 `17n+5` 帧对应 `5n+2` 视频潜步，音频为每秒40潜步。
- 示例：124帧 → 视频37步／音频207步；362帧 → 视频107步／音频603步。
- 三节点共用 `segment_timing.py`。采样器始终按实际输入解析规则，不沿用旧预览的音频边界。
- 自动模式窗口向下吸附，起点按5视频潜步对齐；51帧模式改用15视频潜步／85音频潜步的整数起点网格。最短可推进窗口和尾段可能偏离指定秒数；51不是RoPE的通用周期，也不保证嘴型一致。
- 自定义区间向外吸附，结束位置以真实输入为限。未覆盖区域保留输入，空潜空间中的未覆盖区域不会自动生成内容。无效区间报出具体错误。
- `fps` 是输入图像序列的播放帧率；规划器按其时长换算为24fps的H3预览，不负责替上游模型重采样视频。
- 规则模式的分段数量只是约15秒参考；要预览实际数量，应接入真实潜空间。

## 重抽、条件与缓存

- 标准 `RandomNoise` 的分段实际种子为基础种子加偏移。相同种子在相同绝对位置共享噪声；不同偏移会改变该段（包括重叠区）的初始噪声。`DisableNoise` 仍保持零噪声。
- 一采可按时间裁剪 `minimax_refs` 的参考视频及其音轨。二采也按时间裁剪参考。参考片段未覆盖当前段时不构造空参考张量。
- 两个采样器都会筛选、裁剪并重定位 `minimax_keyframes`。跨边界的引导片段可保留少量起点之前的上下文，以维持原有token相位。
- 对接 ComfyUI 的 `BasicGuider` / `CFGGuider` 条件接口；自定义引导器或噪声实现需遵守同一接口。同步参考不保证生成动作逐帧跟随参考。
- 缓存由每个节点实例独占，写入系统临时目录 `pj_segments_*`，内存只保留校验摘要。改变输入内容、分段边界、条件、模型或采样配置后自动重算；改变种子仍允许保留已锁定结果。
- 缓存读取有磁盘开销，不承诺0秒。节点实例释放或正常进程退出时清理；进程被强制终止可能留下临时文件。缓存不跨重启恢复。没有有效缓存的段会先采样。
- 硬切由后段覆盖重叠区；线性和余弦模式按实际重叠范围融合。

## 精修范围

这是基于开源 H3 模型的自定义潜空间精修流程，不等同于官方 H3-Regenerate-2K。后者的发布状态以 [MiniMax官方仓库](https://github.com/MiniMax-AI/MiniMax-H3) 为准。

保留原音功能保证输出音频潜空间不变；音频仍参与联合模型计算，不保证新画面的口型匹配。分段和采样后卸载模型可降低部分显存压力，但不保证无接缝、无质量损失或不会显存不足。超过模型常用时长、高清精修质量和显存峰值需要实际模型验证。

## 安装与验证

放入 `ComfyUI/custom_nodes/ComfyUI-PJ-SegmentSampler`，重启后端并刷新浏览器。使用 ComfyUI 环境已有的 PyTorch、NumPy；播放器另需可用的 FFmpeg，带声音预览需 soundfile。

在本仓库目录使用所属便携包的 Python 执行：

```powershell
& '..\..\..\python_embeded\python.exe' -s -m unittest discover -s tests -v
Get-Content -Raw js/pj_segment_sampler.js | node --input-type=module --check
```

独立浏览器布局回归页：

```powershell
& '..\..\..\python_embeded\python.exe' -s tests/serve_dashboard.py
```

打开 `http://127.0.0.1:18765`，依次执行4段、20段、变窄、再次4段，检查页面显示PASS且无需拖动节点。此页面使用真实前端扩展与轻量DOM控件宿主，不代替完整ComfyUI画布验证。

模块入口见 [模块地图](docs/MODULE_MAP.md)，已验证范围与待办见 [开发台账](docs/DEV_LOG.md)。许可证：[MIT](LICENSE)。
